# Citeora
Citeora 是一款面向学术研究者、硕博学生和科研工作者的鸿蒙应用HarmonyOS文献管理与引用工具。 文献管理：多级分类整理文献资料，标签与笔记灵活标注。支持标题、作者、DOI 等全文检索，一键定位所需文献。行内编辑元数据，操作零摩擦。 多源导入：支持 Zotero RDF、BibTeX、RIS、CSL JSON/YAML 格式导入，迁移零门槛。输入 DOI 自动从 Crossref 获取元数据，粘贴网页 URL 智能提取学术信息，IEEE Xplore 一键导入。浏览器内自动识别学术页面，捕获元数据与 PDF。 PDF 阅读与批注：内嵌 PDF 阅读器，8 种颜色高亮、下划线、删除线和文字批注，阅读进度自动保存。四种视图模式、文档大纲导航、页内搜索，支持自定义阅读主题。 引用导出 一键生成 BibTeX、APA、GB/T 7714（中国国家标准）引用格式，实时预览，复制即用。 RSS 订阅：订阅学术期刊与预印本 RSS 源，自动刷新推送新文章，感兴趣的一键加入文库。 内置浏览器：直接访问学术网站与数据库，自动检测并下载 PDF，保存常用网站快速访问。 数据安全：Zotero 兼容存储格式，数据完全本地存储。支持外部存储目录，库文件可导出备份与迁移。
